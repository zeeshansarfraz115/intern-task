# Intern Task

This repository contains Python solutions for internship tasks.

## Tasks Included:
- **`script.py`**: A script to perform basic arithmetic operations (addition, subtraction) with user input.
- **`shani.py`**: A dictionary example printing a model name.
- **`task1.py`**: A Rock, Paper, Scissors game running in the terminal.
- **`task2.py`**: An interactive terminal calculator supporting addition, subtraction, multiplication, division, sine, and cosine.

## Requirements:
- Python 3.x
- No external libraries required (uses only standard library modules `math` and `random`).
